mark

The mark shortcode is an inline highlighter — a translucent color wash in light mode, and a bright underline in dark mode (a wash goes muddy on a dark page). The text keeps its normal color either way.

Syntax

{{< mark [color] >}}highlighted text{{< /mark >}}

Colors match the hint / flag vocabulary; omit for the default yellow.

The colors

Here is the default yellow, plus info, note, warning, success, error, and important — all inline, mid-sentence.

Spanning several lines

A highlight can run across a long stretch of text and wrap onto the next line, where each line keeps its own strip instead of stretching into one lopsided box — box-decoration-break at work in light mode.
